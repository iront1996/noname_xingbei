## 二、核心設定與勝負

- 遊戲為紅、藍雙陣營對抗，常見為 4 人（2v2）、6 人（3v3）；較新整理資料亦列 8 人（4v4）。
- 起始士氣：4、6 人模式各隊 15；較新資料的 8 人模式各隊 18。士氣上限一般同起始值；角色／模式特例另算。
- 起始手牌：每位玩家 4 張。一般手牌上限 6。
- 共用基礎牌庫 150 張；用盡時將棄牌堆洗勻作新牌庫。基礎牌、角色卡、專屬卡、標記卡應區分資料類型。
- 第一個回合由紅方標有 First Player 的玩家開始；回合沿其右手邊輪轉（逆時針）。
- **勝利即時判定**：任一方達 5 個星杯，或對手士氣降至 0 以下，立即結束。
- 隊伍「戰績區」中的星石上限 5；分「寶石」和「水晶」，兩者都屬星石；「星杯」與隊員身上的「能量」是不同資源。

**系別**：火、地、風、水、雷、暗、光共七系。**命格／卡牌類別**：血、詠、技、聖、幻共五類；「系別」與「命格」是不同欄位。

## 四、回合／行動流程

1. 回合開始前。
2. 回合開始時。
3. 行動階段開始前：例如先處理中毒，再處理虛弱，並檢查其餘相關效果。
4. 行動階段開始時：技能觸發、可能的啟動、無法行動檢查。
5. 行動階段：預設**必須**從合法行動中執行一個。可選：
   - **攻擊**：執行攻擊行動。
   - **法術**：使用法術牌或法術技。
   - **購買**：摸 3 張牌，己方戰績區獲寶石 1 + 水晶 1（受 5 上限制約）。
   - **合成**：摸 3 張牌，耗己方戰績區任意 3 星石，增星杯 1；普通合成會令敵方士氣 -1。
   - **提煉**：將己方戰績區的 1～2 星石轉為這名角色的能量（受能量上限制約）。
6. 行動完成後的觸發、允許的追加行動、回合結束時／結束後觸發，輪到右手邊下一人。

攻擊／法術 = **一般行動**；購買／合成／提煉 = **特殊行動**。
購買、合成只有在摸 3 張後**不會超過當前手牌上限**時才合法：一般上限 6 時，行動前手牌必須 ≤3。合成還須有至少 3 顆己方戰績區星石；提煉至少有 1 顆且本人的能量有空位。戰績區 5 顆滿時仍可購買，但不增加或置換星石；戰績區 4 顆時購買只能擇一種類加入。

**啟動技**：一般在自己的行動階段開始時使用，每回合至多啟動一次；啟動後不能做特殊行動，須能繼續攻擊或法術。**追加行動**通常可放棄，未使用的不能保留到下一回合；但有「立刻執行」字樣者另受時點限制。遊戲**沒有固定的回合開始摸牌階段**。

## 五、攻擊與應戰

- 主動攻擊：使用一張攻擊牌或技能，指定敵方角色；一般攻擊牌基礎傷害 **2 點**。
- 防守者可依規則選擇應戰、以聖光／聖盾擋下、或承受命中。應戰以同系攻擊牌抵擋當前攻擊，改攻擊**另一名對手**；不可應戰回剛才攻擊自己的角色，也不可選隊友。
- **暗滅**可以應戰其他五種屬性攻擊；暗滅本身不可被應戰，但可被聖光、聖盾抵擋。
- **主動攻擊命中**：己方戰績區得寶石 1；**應戰攻擊命中**：己方得水晶 1；超過戰績區上限則不增加。攻擊被應戰、聖光或聖盾抵擋皆視為未命中。
- **強制命中**：略過一般應戰／聖光／聖盾的防禦機會；場上的盾不因被無視而消耗。
- **無法應戰**：只排除應戰，不自動排除聖光／聖盾。切勿和強制命中混淆。
- 命中與實際傷害量是兩件事：即使傷害後被治療抵禦至 0，攻擊仍算命中，該獲取的星石仍可獲取。
- 若攻擊未命中會觸發回應，先解決此回應，再處理下一段應戰攻擊。

## 六、法術／持續效果

- **聖光**：在自己遭攻擊或魔彈時抵擋；並非可以於自己回合任意使用的攻擊法術。
- **聖盾**：置於目標角色前，遇適用的攻擊或魔彈時可抵擋並移除；具體的防禦優先順序需依卡面／FAQ。
- **中毒**：在受放置者行動階段開始前造成 1 點**法術傷害**並移除；一角色可有數個中毒。多個效果結算依時序及座位規則。
- **虛弱**：在受放置者行動階段開始前，選擇跳過行動階段，或**非傷害性**摸 3 張再照常行動；每角色一般至多一張。摸牌超限同樣會爆牌扣士氣，且不能以治療抵禦。
- **魔彈**：從使用者右手邊最近的對手開始；可承受法術傷害（初始 2）、以聖光／聖盾擋下，或打出魔彈繼續傳遞（每次傳遞傷害 +1）。同一輪每位玩家僅能承接一次；按較新資料，跑完一輪後可開始下一輪且累積傷害不清零。傳遞者與命中者／傷害來源應作為規則狀態記錄。
- 大部分法術並不直接取得星石，除非角色卡特別注明。若規則寫「目標角色」，可包含自己；「目標隊友」不含自己；「目標對手」只選對方。
- 中毒、虛弱、聖盾等是**基礎效果**；同名基礎效果一般不可重複放在同一角色前，明確特例如中毒例外。專屬卡形成的**專屬效果**不能直接當成基礎效果移除。

## 七、傷害、治療、爆牌、士氣

- **攻擊傷害**：攻擊命中造成；其他一般為**法術傷害**（若技能特別註明從其規定）。
- 每承受 **1 點最終傷害**，從牌庫**摸 1 張牌**。一般抽牌（購買、合成、虛弱、技能抽牌）與「傷害摸牌」不同，不會因為有抽牌就自動觸發「受到傷害」技能。
- **治療**：通常每 1 點治療可抵禦 1 點攻擊或法術傷害；角色可選用部分、全部或不用。預設每角色治療上限 2；不可抵禦非傷害摸牌。
- **爆牌**：手牌數一旦超過當下上限，玩家秘密挑選超出的牌、棄至上限；**每因爆牌棄 1 張，己方士氣 -1**。傷害造成的摸牌與普通摸牌都可能爆牌；傷害不等於直接降士氣。
- 預設**能量上限 3**；寶石可支付標示水晶的必殺技消耗，但水晶不得反向支付標示寶石的消耗，除非特例。
- 一般**治療、能量、手牌、星石**上限都可能被角色技能覆蓋；程式不得硬編碼全局固定數字。

### 六個傷害結算時點

1. ① 攻擊／法術**發動宣言**。
2. ② 攻擊／法術**命中判定**。
3. ③ **造成傷害量**（傷害來源、目標與修正）。
4. ④ **治療抵禦**選擇。
5. ⑤ **實際發生傷害量**（扣除抵禦後）。
6. ⑥ **實際承受傷害**（最終傷害摸牌／爆牌等後續處理）。

標示 ①～⑥ 的技能或卡面以指定時點結算。尤其 ③ 以前的效果不應錯排到治療④以後；0 最終傷害仍可能有「已命中」的事實。對同時多名角色造成傷害，依傷害來源右手邊起的逆時針順序處理，若卡面更明確則以卡面為準。

## 八、技能分類／共通關鍵詞字典

| 關鍵詞 | 正確理解／工程備註 |
|---|---|
| 普通技 | 不需消耗能量；仍受條件／時點限制 |
| 必殺技 | 需支付技能指定寶石／水晶能量 |
| 獨有技 | 角色專屬的牌庫卡牌或所標記的能力（須持有對應牌） |
| 專屬技／專屬效果 | 使用角色專屬卡與狀態，與基礎效果分開 |
| 被動技 | 條件成立時自動處理 |
| 回應技／響應技 | 在指定事件與時機選擇是否觸發 |
| 啟動技 | 自己行動階段前段、每回合一次；禁止後續特殊行動 |
| 法術技 | 使用法術行動的技能 |
| 目標角色／隊友／對手 | 角色=可自己或任何玩家；隊友=不含自己；對手=敵方 |
| 其他角色 | 不含發動者 |
| 強制命中 | 不能應戰、聖光／聖盾也不能抵擋 |
| 無法應戰 | 不能應戰但可依規則使用聖光／聖盾 |
| 抵擋攻擊 | 該攻擊視為未命中 |
| 承受攻擊 | 攻擊命中；後續另計治療／傷害 |
| 抵禦傷害 | 減少最終傷害量；不反轉命中判定 |
| 移除 | 將指定效果卡送往適用棄牌位置；專屬卡依專屬規則返回 |
| 打出／使用／展示 | 區分揭露卡牌、啟動效果與進棄牌堆的時機 |
| 棄牌／棄置 | 按效果要求放入棄牌堆；爆牌通常暗棄 |
| 基礎效果 | 一般場上持續的基礎牌效果；同名原則一個、特例除外 |
| 橫置／重置 | 角色卡姿態改變；不當然代表每回合只能橫置一次 |
| 形態／轉為形態 | 形態限制技能啟動；同形態轉同形態不等於發生轉換 |
| 增加／減少／獲得 | 通常會觸發相應條件；不可與「轉移」混用 |
| 轉移 | 從一端搬往另一端；第三方名詞頁指出不等同獲得或增減 |
| 額外行動／立刻執行 | 額外行動一般當回合有效；明示「立刻」則限制執行順序 |
| 強制 | 按圖標在相應條件滿足時不得自主省略；注意與「強制命中」區分 |
| 恆定 | 對應版本圖標表示持續有效且不受一般作用取消，特例看卡面 |
| 持續 | 指效果保持有效的期間；終止條件另列 |
| 丟失目標 | 發動時無合法目標，技能不能發動 |
| 不完全／部分發動 | 有合法目標但部分或全部效果無法實現，通常仍可發動 |
| 溢出 | 資源取得超過上限，超額部分無效；另看「無視上限」 |
| 重複回應 | 同一事件時點同一技能一般不得重複觸發 |
| 同系／異系 | 以七系判別；「異系」是所列牌兩兩不同 |
| 角色類別／命格 | 血、詠、技、聖、幻；不同於元素系別 |

注意：本節是檢索索引，**不是所有角色技能詞條的窮舉**。角色專有指示物、專屬蓋牌、獨有技名稱、人物形態與各擴充新機制，要依角色索引逐張對照。英文代碼與中文別名應映射為同一內部機制，而非按字面不同就做兩套規則。

## 九、選角與版本隔離

- 常見 RD（Random Draft）、BP（Ban/Pick）、3 選 1、CM01 比賽模式；較新資料另有暗黑議會、酒館等選角流程。各模式角色池大小與禁角順序不能套用到其他模式。
- 後續角色擴充、10 週年版、星落漣漪與神子創臨，以及《破曉》，在角色池、機制及初始設定可能不同。應設 `rulesetId`／`rulesVersion`／`expansionIds`，禁止對局中無聲升級版本。
- 完整 PDF 目錄已覆蓋其當時的 31 名角色及 FAQ，但**不是截至 2026 年所有角色**的完整技能資料庫。
- 第三方百科與舊 PDF 在部分細節存在版本差異，例如 8 人起始士氣、某些非合成取得星杯的特例、魔彈延伸傳遞、無法行動與封印的互動。將差異納入版本測試，不要取代來源文字後當成唯一官方裁定。

## 十、聯機規則引擎／V3 斷線恢復檢查清單

**必要的權威狀態**：
`rulesetId`、`gameId`、`turnPlayer`、`phase`、`subphase`、`currentAction`、`pendingChoice`、`resolutionQueue`／`responseStack`、`damageTiming(1..6)`、攻擊／法術來源與目標、應戰鏈／魔彈累積、已用回應／啟動標記、行動額度、所有玩家手牌與暗牌、抽／棄牌堆順序、雙方士氣／星石／星杯、個人治療／能量／形態／標記與場上持續效果。

**回放與恢復**：
- 任何等待玩家作選擇的階段，包括防禦、應戰、治療抵禦、虛弱、爆牌暗棄、寶石／水晶選擇、技能回應和合法目標，都要可快照並恢復。
- 房主重整後，不得重複抽牌、扣士氣、支付能量、取得星石、再次播放已結算的必殺技或重派初始手牌。
- 伺服器裁定合法行動；前端僅顯示權威可選清單，不以前端操作成功推定狀態成立。
- 需記錄 deterministic event id／seq、隨機種子或牌庫順序，並使重送／重播具冪等性。
- 玩家可見資料與隱藏資訊分開；快照不應將其他玩家的完整手牌洩漏給客戶端。
- 勝利觸發後立即凍結動作；對逾期封包、重複回應與已結算 pendingChoice 設拒絕條件。

**優先的回歸測試**：
1. 6 手牌受 2 傷害，未治療：摸 2 後暗棄 2，士氣 -2；若治療抵禦 2 則攻擊仍命中但不摸傷害牌。
2. 4 手牌、上限 6，不能購買／合成；3 手牌可購買（若其他條件合法）。
3. 暗滅可應戰普通屬性攻擊；不能被應戰，但可被聖光／聖盾抵擋。
4. 強制命中略過一般防禦；無法應戰仍允許適用的聖光／聖盾。
