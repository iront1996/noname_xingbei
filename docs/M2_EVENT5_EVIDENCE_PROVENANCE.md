## Cross-invariants

- The accepted predecessor and successor wait must share room, active host session, pinned engine build, root instance, and exact ordered four-seat roster.
- The successor actor and native event instance must differ from the prior action actor/event; its current seat binding must be an ordinary authenticated player with a current connection generation.
- A validated phaseOver fence must precede the successor input wait. Native completion ordinals are monotonic and evidence instances cannot be reused; capture ordinal is a separate counter.
- The successor wait has no allocated choice, delivery, timer, trustee result, action settlement, or authority submission.
- Any stale session/root/build/seat/event, pending child, non-increasing ordinal, inconsistent private projection, or unexpected Event #5/revision transition fails closed.
- The review assessor is not a provenance authority. Its structural-shape result is explicitly named `reviewObservationShapeValid`; classifications are `manager_scoped_review_candidate`, not trusted proof. Only the manager integration constructs its input from current manager-owned/authenticated records, and neither path is connected to authority submission.

## V3 seat-state interface status

The isolated V3 schema v2 transport contract now has a dedicated server-only projector over the same manager-accepted successor pre-action envelope. It validates the Card Ledger, limited Effect State, and Turn/Resource projections again; public output is restricted to active seat, native phase, reviewed public character/side/hand counts and visible team resources. Private output is only HMAC-derived opaque IDs for the authenticated recipient's own physical hand cards. Messages do not contain host/session identifiers, private state digests, raw card IDs/names, skills/storage, or another seat's private hand. State sequence/version is a per-seat server stream counter, not a digest or native completion ordinal. `pendingChoice` is null because no choice was allocated at this diagnostic gate. The manager API defaults to deny and requires an injected ordinary-seat authorization callback; after view construction it rechecks the callback, current binding generation and active host record. The internal envelope, projection key and sequence map are cleared/destroyed with the HostSession. This is not a socket transport, HALL integration, or M3 acceptance.

Digest-domain cross-invariants: authority predecessor=`xingbei_authority_state_v2` (accepted SHA-256 state); successor T3 `stateDigest`/HMAC=`xingbei_native_private_successor_preaction_capture_v1` private projection/fence preimage; V3 `stateSequence/stateVersion`=per-recipient stream cursor; `nativeCompletionOrdinal`=managed native event completion ledger; capture ordinal=accepted capture ordering. No equality between these domains establishes state continuity. The authority bridge from Event #4 through phaseOver/actor rotation to a future second-seat action remains unavailable, and the Event #5 draft's private before/after transition proof remains unavailable until a supported action transition exists.
